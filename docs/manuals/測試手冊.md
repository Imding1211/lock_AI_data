## 1. 硬體維修技師 (Hardware Technician) 測試案例
回答範疇：內部構造、鎖舌原理、硬體故障排除、更換評估

| # | 測試問題 | 預期結果 |
|---|---------|---------|
| H-1 | 預售屋想換電子鎖要提供什麼資訊供技師評估？ | 告知需提供現有鎖體正面及鎖匣照片，以便評估側板規格。 |
| H-2 | 什麼是電子鎖的側板和受口？ | 解釋鎖匣外鐵片與門框孔位的定義，這會影響型號選擇。 |
| H-3 | 推拉式和把手式電子鎖的開門動作差異？ | 解釋推拉式為直接進門，把手式則需下壓把手的機械區別。 |
| H-4 | 全自動鎖匣的鎖舌感應機制是什麼？ | 解釋其具備感應器，當門關閉後會自動驅動鎖舌上鎖。 |
| H-5 | Dormakaba 鎖舌在室內拉不開門的緊急處理？ | 指導「先將門板向內推緊，再拉動把手」的緩解動作。 |
| H-6 | Dormakaba 鎖在室外推不開門的緊急處理？ | 指導「先拉緊把手使門閉合，完成解鎖後再用力推動」。 |
| H-7 | 門扇反弓會對鎖舌造成什麼具體影響？ | 指出鉸鏈區域擠壓問題會導致鎖舌與受口片卡澀難開。 |
| H-8 | 出現關鎖失敗警報時，使用者可以如何自行初步排查？ | 指導在開門狀態下測試鎖栓伸縮，確認是否為受口位移造成。 |
| H-9 | Dormakaba 雙重認證模式啟動後會有什麼現象？ | 說明單一指紋或密碼將無法開門，需兩者同時驗證。 |
| H-10 | 人臉辨識模組亮紅燈的含義？ | 說明鏡頭正在主動啟動紅外線辨識，屬於正常工作狀態。 |

## 2. 報價與客服專員 (Sales Representative) 測試案例
回答範疇：服務預約流程、代工規範、保固判定、售後說明 (嚴禁報價)

| # | 測試問題 | 預期結果 |
|---|---------|---------|
| S-1 | 預約師傅到府安裝電子鎖的具體流程？ | 說明諮詢、照片評估、選型、支付訂金、排期安裝及教學。 |
| S-2 | 小米電子鎖代工安裝為什麼一定要看門扇照片？ | 解釋是為了確認現場環境（如側板尺寸）是否符合安裝標準。 |
| S-3 | 師傅完成安裝後會提供哪些教學服務？ | 告知會現場教學管理員設定、用戶錄入及緊急供電操作。 |
| S-4 | 自備鎖請你們代工，如果之後壞了有保固嗎？ | 說明代工服務僅針對安裝品質，產品本身故障需洽原購買商。 |
| S-5 | 林口以外的地區有提供電子鎖安裝服務嗎？ | 告知實體門市位置並強調安裝服務可提供跨區支援。 |
| S-6 | 遺失實體鑰匙導致無法進門，這在保固範圍內嗎？ | 明確告知鑰匙遺失屬於人為因素，不包含在免費保固中。 |
| S-7 | 如果我想更換整組鎖體，建議先準備什麼資料？ | 引導使用者提供現有門鎖的照片與門厚資訊以利作業。 |
| S-8 | 電子鎖更換完成後，舊的傳統鎖會如何處理？ | 說明技師通常會將舊鎖交還客戶保存，不負責回收。 |
| S-9 | 為什麼建議在早上十點半或下午一點半施工？ | 解釋是為了遵守社區大樓的噪音管制規定，避免吵到鄰居。 |
| S-10 | 有網路連線功能的電子鎖，對生活有哪些具體好處？ | 提及可異地遠端開門、即時收到家人到家通知及紀錄查詢。 |

## 3. 門市與規格助理 (Store Assistant) 測試案例
回答範疇：門市資訊、電池建議、說明書搜尋、一般規格

| # | 測試問題 | 預期結果 |
|---|---------|---------|
| W-1 | 鎖市林口門市的營業時間為何？ | 提供週一至週六 09:30-21:30 等正確資訊。 |
| W-2 | 新北市林口區中山路的門市地址？ | 提供新北市林口區中山路526號之2。 |
| W-3 | 門市除了電子鎖還有提供印章服務嗎？ | 回答有提供，包含印章刻印代工與名片製作。 |
| W-4 | 電子鎖完全沒電時，有哪些緊急供電方案？ | 指導使用 9V 方型電池或行動電源透過 USB 接孔供電。 |
| W-5 | 為什麼電子鎖不建議混用不同品牌的電池？ | 解釋不同電壓可能導致漏液風險，強力推薦單一品牌鹼性電池。 |
| W-6 | 老人家指紋較淺，在設定上有什麼建議？ | 建議同一手指重複設定 3 次以上，或改用人臉、掌靜脈。 |
| W-7 | 鎖市有賣 Milre 美樂 6500F 嗎？ | 回答有提供此型號產品的銷售與服務。 |
| W-8 | 哪裡可以下載 GL220 電子鎖的說明書？ | 提供 GL220 的 Google Drive 分享連結。 |
| W-9 | 我想找 FA9000 電子鎖的操作手冊。 | 提供 FA9000 的 Google Drive 連結。 |
| W-10 | ML660 的故障排除手冊連結？ | 提供 ML660 的 Google Drive 連結。 |

## 4. APP 設定專家 (APP Specialist) 測試案例
回答範疇：YouTube 教學內容、多品牌與多型號 App 設定步驟

| # | 測試問題 | 預期結果 |
|---|---------|---------|
| Y-1 | AS701 智慧鎖如何進入密碼登記模式？ | 打開電池蓋按「+」鍵，輸入原密碼後按 * 鍵進入設定。 |
| Y-2 | 如何在 AS701 上新增 RFID 感應卡？ | 按下登記鍵後，將卡片貼近感應區並按 * 鍵完成。 |
| Y-3 | A90 電子鎖完全沒電，如何用行動電源喚醒？ | 按壓底部圓蓋右轉取出，使用 Type-C 線連接供電。 |
| Y-4 | Philips Alpha 怎麼設定遠端金鑰？ | 引導參考 GDrive 上的 APP 遠端操作手冊步驟。 |
| Y-5 | 如何設定 AS701 的遙控器功能？ | 按下登記鍵後，按下遙控器 OPEN 鍵並以 * 鍵確認。 |
| Y-6 | ML550 電子鎖的基本操作說明在哪看？ | 提供 ML550 專屬的 GDrive 使用說明書連結。 |
| Y-7 | Chatlock AI-99 臨時密碼的首位數字有什麼規定？ | 明確指出臨時密碼的第一個數字必須設定為「1」。 |
| Y-8 | AI-99 如何查看過去的開鎖紀錄？ | 指導在 App 主介面點選「相簿/紀錄」功能選項。 |
| Y-9 | 為什麼播放 AI-99 的語音留言需要驗證管理員？ | 說明是基於隱私安全規範，確保只有授權者可聽取。 |
| Y-10 | 如何在 A90 上完成掌靜脈的錄入？ | 提示手掌應保持在鏡頭正前方 15 至 30 公分處進行掃描。 |
