## 一、Semantic Pre-chunking 架構升級（03/19 – 03/20）

### 背景

原架構在 Silver → Gold 階段使用 `RecursiveCharacterTextSplitter` 做固定長度切塊，改為在 Bronze → Silver 階段由 LLM 依語意邊界預先切塊（Semantic Pre-chunking），搭配 HyDE 格式與 Small-to-Big Retrieval。

### 異動

| commit | 說明 |
|--------|------|
| `bda1030` (03/19) | 將 chunk_size / chunk_overlap 從 hardcode 移至 `config.toml` |
| `d618ac0` (03/19) | Video 與 YouTube 的 Bronze → Silver 改用 Semantic Pre-chunking，LLM 產出 JSON Array |
| `18ec9b5` (03/20) | 全面更新文件（架構書、處理流程、測試手冊、RAG 整合規範）反映新架構 |

### 技術要點

- Silver 產出從「單一 Document JSON」變為「JSON Array（多知識點）」
- 每個知識點包含 HyDE 格式的 `page_content`（常見問題 + 知識內容）
- `metadata` 新增 `chunk_index` 和 `raw_text` 欄位，支援 Small-to-Big Retrieval
- `seed_pgvector.py` 不再切塊，直接將 Silver 知識點轉為 Documents
