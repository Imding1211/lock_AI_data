## 技術設計

### 處理流程

對每支 `storage/bronze/youtube/{video_id}.json`：

1. **讀取 Bronze JSON** → 取得 `video_id`、`url`、`title`、`transcript`
2. **Regex 時間戳轉換** → `[MM:SS]` 轉為 `[[MM:SS]](https://youtu.be/{video_id}?t={T}s)`
3. **LLM 重寫** → 透過 `get_llm()` + system prompt + JSON schema，產出 `page_content` + `metadata`
4. **強制覆寫 source 欄位** → `source_type="youtube"`、`source=video_id`、`url=原始url`
5. **寫入** `storage/silver/youtube/{video_id}.json`

### Regex 時間戳轉換

Pattern：`\[\d{1,2}:\d{2}(?::\d{2})?\]`

| 轉換前 | 轉換後 |
|--------|--------|
| `[00:00]` | `[[00:00]](https://youtu.be/Bg3hu2shcVo?t=0s)` |
| `[01:15]` | `[[01:15]](https://youtu.be/Bg3hu2shcVo?t=75s)` |
| `[1:30:00]` | `[[1:30:00]](https://youtu.be/Bg3hu2shcVo?t=5400s)` |

時間戳在送入 LLM **之前**先轉為 deep link，LLM 只需保留連結格式不動即可。

### config.toml 新增區段

```toml
[pipelines.youtube_silver]
llm_provider = "vertexai"
llm_model = "gemini-2.5-flash"
temperature = 0.3
```

使用獨立區段（非復用 `youtube_vision`），因為此階段是純文字 LLM，不需要視覺能力，且 temperature 不同（0.3 vs 0.1）。

### 與 `process_video.py` 的差異

| 項目 | `process_video.py` | `process_youtube.py` |
|------|-------------------|---------------------|
| 輸入格式 | `.txt`（純文字逐字稿） | `.json`（含 video_id / url / title / transcript） |
| 時間戳處理 | LLM 移除時間戳 | Regex 轉為 YouTube deep link，LLM 保留 |
| LLM 任務 | 糾錯 + 去噪 + 結構化重寫 | 重寫為操作設定指南（保留連結） |
| metadata.source | 檔名（`Chainlock 設定教學.txt`） | video_id（`Bg3hu2shcVo`） |
| 額外 metadata | 無 | `url`（影片完整 URL） |

### 防呆機制

- **強制覆寫 source 欄位**：`source_type`、`source`、`url` 由腳本控制，不受 LLM 幻覺影響
- **LLM 回應驗證**：檢查 `page_content` 非空、`metadata` 含必要欄位（brand / model / category）
- **冪等執行**：已存在的 Silver 檔案自動跳過，`--force` 可覆寫
- **Rate limiting**：API 呼叫間隔 1 秒

### Silver JSON 輸出格式

```json
{
  "page_content": "# AI-99 清理緩存設定指南\n\n[[00:00]](https://youtu.be/Bg3hu2shcVo?t=0s) ...",
  "metadata": {
    "brand": "Chainlock",
    "model": "AI-99",
    "category": "setup",
    "source_type": "youtube",
    "source": "Bg3hu2shcVo",
    "url": "https://www.youtube.com/watch?v=Bg3hu2shcVo"
  }
}
```

## 驗證方式

```bash
# 1. Config 載入
python -c "import tomllib; print(tomllib.load(open('config.toml','rb'))['pipelines']['youtube_silver'])"

# 2. 執行 pipeline
python pipeline/bronze_to_silver/process_youtube.py --verbose

# 3. 確認輸出
ls storage/silver/youtube/*.json
cat storage/silver/youtube/Bg3hu2shcVo.json | python -m json.tool

# 4. 驗證 deep link 格式
grep -o '\[.*\](https://youtu.be/.*?t=.*s)' storage/silver/youtube/Bg3hu2shcVo.json
```
